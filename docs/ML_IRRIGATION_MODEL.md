# KhetAI Experimental ML Irrigation Model (`ML_IRRIGATION_MODEL.md`)

## 1. Architectural Architecture & Data Flow

KhetAI implements a **Hybrid Decision Architecture** where the FAO-56 Agronomic Engine acts as the primary recommendation system, while the Experimental ML Model provides side-by-side predictions trained on historical research datasets:

```
[ External Zenodo Dataset (DOI: 10.5281/zenodo.19725692) ]
                            │
                            ▼
[ Feature Preprocessing & Log10 Target Transformation ]
                            │
                            ▼
[ Pure JS Ridge Linear Regression (R² = 0.9421) ]
                            │
                            ▼
[ Model Artifact Saved: backend/ml/models/sugarcane_irrigation_v1.json ]
                            │
                            ▼
[ API Endpoint: POST /api/ml/predict ]
  ├── Agronomic Baseline (FAO-56 ET₀ + Soil Water Depletion Budget) ──► Primary Decision
  └── Experimental ML Model (Pure JS Inference) ──► Side-by-Side Comparison
```

---

## 2. Model Specification

- **Model Version**: `sugarcane-irrigation-v1`
- **Algorithm**: Multiple Linear Regression (Ridge OLS with \(\lambda = 10^{-3}\))
- **Target Variable**: `drip_liters_per_day` (\(\log_{10}\) transformed for numerical stability)
- **Target Generation Method**: **Category D — Generated by ML Pipeline** (Outputs from CatBoost-based model simulation in SIDSS framework paper, Zenodo DOI: 10.5281/zenodo.19725692)
- **Training Samples**: 1,050 rows (70%)
- **Validation Samples**: 225 rows (15%)
- **Test Samples**: 225 rows (15%)

### Dual-Scale Evaluation Metrics on Held-Out Test Set (225 rows)

| Scale | Model | MAE | RMSE | \(R^2\) Score |
|---|---|---|---|---|
| \(\log_{10}\) Scale | Linear Regression | **0.1050** | **0.1277** | **0.9421** |
| \(\log_{10}\) Scale | Mean Baseline | 0.4232 | 0.5322 | -0.0058 |
| Original Liters/Day | Linear Regression | **4.2286 × 10⁸** | **1.0103 × 10⁹** | **0.8507** |
| Original Liters/Day | Mean Baseline | 1.7248 × 10⁹ | 2.6309 × 10⁹ | -0.0122 |

## 3. Pure JS Inference Engine

The model runs in Pure JavaScript without requiring external Python runtime dependencies:

$$\hat{y}_{\text{log10}} = w_0 + \sum_{j=1}^{13} w_j \left( \frac{x_j - \mu_j}{\sigma_j} \right)$$

$$\text{Predicted Water Requirement (liters/day)} = 10^{\hat{y}_{\text{log10}}}$$

### 13 Input Features (Standardized)
1. `stomataopenclose` (Stomatal ratio)
2. `nitrogen` (Soil/plant N)
3. `chloropyll` (SPAD chlorophyll index)
4. `phosphorus` (Soil/plant P)
5. `leafhumidity` (Leaf moisture %)
6. `leafevaporation` (Evaporation mm/d)
7. `evapotranspiration` (ET₀ mm/d)
8. `stageCode` (Germination=0, Tillering=1, GrandGrowth=2, Maturity=3, Drying=4)
9. `soilph` (Soil pH)
10. `soilhumidity` (Topsoil moisture %)
11. `microclimatictemp` (Air temperature °C)
12. `seasonCode` (Monsoon=0, Summer=1, Winter=2)
13. `microclimaticwindspeed` (Wind speed km/h)

## 4. Performance Limitations & Scientific Caveats

> [!WARNING]
> **Dataset Performance vs. Real-World Field Accuracy**
> The metrics reported above (\(R^2 = 0.9421\) log scale, \(R^2 = 0.8507\) original scale) describe fit on a held-out test split of an **external model-simulated research dataset** (Zenodo DOI: 10.5281/zenodo.19725692).
> They **do not establish real-world field accuracy** or empirical performance on real farms.
> Target values (`drip_liters_per_day`) were generated by another ML pipeline (CatBoost model simulation), not direct physical water flow meter readings.

## 6. Non-Interference Guarantee

The ML prediction **never overrides** the Agronomic Baseline recommendation. If the ML model artifact is missing, unparseable, or encounters invalid input features, the API handles it gracefully and returns `AGRONOMIC_BASELINE` as the sole recommendation engine.
